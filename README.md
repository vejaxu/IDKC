# IDKC

基于论文 **Kernel-based clustering via Isolation Distributional Kernel** 的 MATLAB 实验项目，支持固定随机种子的参数搜索、匈牙利标签对齐、NMI / ARI / macro-F1 评价和 CSV 结果导出。

- 论文：Ye Zhu、Kai Ming Ting，Information Systems 117 (2023), 102212，[DOI](https://doi.org/10.1016/j.is.2023.102212)。
- 作者参考实现：[zhuye88/IDKC](https://github.com/zhuye88/IDKC)。
- 本项目核心算法沿用作者参考实现；搜参、评价及结果保存由实验层组织。

## 环境与运行

本次实验在 MATLAB R2025b 中完成。核心代码使用 Statistics and Machine Learning Toolbox 的 `pdist2`、`datasample` 和 `tiedrank`；`FindMode.m` 还使用 `gather`，运行环境需提供该函数。主流程使用 CPU 和稀疏核特征。

数据集为 MAT 文件，包含：

| 变量 | 要求 |
|---|---|
| `data` | 有限数值矩阵，形状为 n × d，每行一个样本 |
| `class` | n 个有限数值类别标签，支持行向量或列向量 |

修改 `main.m` 中的路径及参数，然后在项目根目录执行：

```matlab
main
```

`main.m` 是 IDKC 的唯一运行入口，可在 MATLAB 编辑器中点击“运行”。当前配置使用已转换的 `results/_inputs/dlpfc_151507.mat`；运行其他数据集时修改 `data_file`。脚本根据自身位置加载项目函数，输出目录自动取 MAT 文件名，例如 `AC.mat` 对应 `results/AC/`。代码不能直接加载 `.pkl`，需先转换为含 `data` 和 `class` 的 MAT 文件。

预处理将每个属性 min-max 归一化到 [0, 1]，常量属性设为 0.5。簇数 k 取真实标签的类别数量。可视化及对比实验是独立示例，运行前需修改各脚本的数据路径和参数；它们不会由 `main.m` 自动执行，也未纳入本次 IDKC 结果表。

## 算法流程

1. **核特征构建**：每次抽取 ψ 个中心，以中心之间的最近邻距离建立隔离球，重复 t 次形成稀疏二值特征。
2. **种子选择**：在 s 个候选点上计算点到整体分布的相似度、q 近邻的局部对比度和分离程度，选择 k 个种子。
3. **簇增长**：以簇成员的平均核特征表示簇分布，吸收相似度最高且超过阈值的未分配点，阈值逐轮乘以 v。
4. **Refinement**：对形成的簇进行归属调整，得到 DKC 原始标签。
5. **评价与导出**：对齐标签，计算指标，保存参数搜索结果和最佳运行的标签。

核心实现与作者源码一致，但不是对论文伪代码的逐行翻译。例如种子分离度使用核特征欧氏距离，点到分布相似度省略统一的 1/t，剩余点分配及 refinement 停止逻辑也存在细节差异。本项目目前保留这些参考实现行为；可能出现的未分配点在评价和输出中显式保留。

## 搜参逻辑

### 当前参数

| 参数 | 含义 | 配置 |
|---|---|---|
| ψ | 每次构建核分区的抽样大小 | `2,4,6,8,16,24,32,48,64,80,100,200,250,500,750` |
| seed | 随机种子 | `42,3407,4079,2024,0` |
| q | 种子选择的近邻数，对应 `DKC` 的 `Kn` | `round(n × [0.05,0.10,...,0.50])` |
| t | 随机分区次数 | `100` |
| v | 增长阈值衰减系数，对应论文 ρ | `0.9` |
| s | 用于种子选择的候选样本数 | `min(n,10000)` |
| k | 簇数 | 真实类别数 |

q 取整后去重并排序，保留 `1 <= q < s`；ψ 保留 `2 <= ψ <= n`。当前 ψ 范围在 750 截止，论文表 A.1 还包含 1000、2000、2500，需要时可在 `main.m` 中扩展。

### 搜索及选择顺序

```text
对于每个 ψ：
    对于每个 seed：
        遍历所有有效 q：
            重置 rng(seed, 'twister')
            加载数据 → 归一化 → 构建核 → DKC → 得到标签
            匈牙利对齐 → 计算 NMI、ARI、macro-F1
        按 NMI 选择该 seed 的最佳 q
        保存同一次运行的 NMI、ARI、macro-F1 和耗时
    对五个 seed 的最佳运行计算平均指标和平均耗时
按平均 NMI 选择最佳 ψ
在最佳 ψ 下，选择单次 NMI 最高的 seed 作为 best_run
保存该运行以及最佳 ψ 下全部五个 seed 的最佳标签
```

每个 q 都重新设置相同的 seed，因此同一 `(ψ, seed)` 下的核划分和候选样本相同，q 的比较不混入重新抽样的差异。每个候选仍独立加载数据和构建核，以记录实际从加载到得到标签的耗时。

NMI 是唯一的选参指标；ARI 和 macro-F1 取自 NMI 获胜的同一运行，不单独挑选各自最大值。选择和平均均使用完整浮点精度，打印和保存时才保留四位小数。完全相同的 NMI 保留较小 q；ψ 或 seed 完全并列时，保留配置顺序中的第一个。四舍五入后相同的分数，在完整精度下仍可能不同。

这是使用真实标签确定 k 和选择参数的实验评价口径，实际无标签应用需另行确定选参方法。

## 指标与计时

匈牙利算法对簇与真实类别进行一对一匹配，目标是最大化匹配正确的样本数。对齐标签采用真实标签的原始编号。NMI、ARI 对标签编号的置换不敏感。

Macro-F1 对所有真实类别等权平均：

```text
F1(c) = 2 × TP(c) / (真实属于 c 的样本数 + 对齐后预测为 c 的样本数)
macro-F1 = 各真实类别 F1(c) 的平均值
```

未命中的真实类别也参与平均。DKC 的原始标签 0 表示未分配，不参与匈牙利匹配；未分配点和未匹配簇保留在 NMI / ARI 中，在 F1 中计入所属真实类别的漏判，对齐标签保存为 `NaN`。样本不会被丢弃，也不会将多个预测簇合并成一个类别来抬高指标。

| 时间字段 | 口径 |
|---|---|
| `LoadToLabelSeconds` | 从单次加载 MAT 文件开始，到 DKC 返回标签结束；包含归一化、核构建、种子选择、增长和 refinement，不包含评价及 CSV 写入 |
| `MeanLoadToLabelSeconds` | 每个 ψ 下五个 seed 的最佳 q 运行耗时的平均值 |
| `SearchSeconds` | 参数循环总耗时，包含所有候选运行、评价和检查点写入；不含前置数据检查及最终结果导出 |

时间依赖硬件、MATLAB 初始化、缓存和系统负载，重复实验通常不会完全相同。

## 结果保存

输出直接保存在 **`results/<dataset>/`**，不创建时间戳目录。再次运行同一数据集会覆盖同名 CSV。整个 `results/` 由 `.gitignore` 忽略，因此下表所述 CSV 需要在本地运行生成，或单独共享。

每个数据集完整运行并保存结果后，还会更新共享汇总表 **`results/idkc.csv`**。新数据集追加一行，已存在的数据集覆盖原行，其他数据集的记录保留。以 MAT 文件名（不含扩展名）作为唯一键，忽略大小写，例如 `AC.mat` 与 `ac.mat` 对应同一记录；不同目录下的同名 MAT 文件也视为同一个数据集。先写临时文件再替换汇总表，避免写入中断留下不完整 CSV。

汇总表保存以下字段：

| 字段 | 含义 |
|---|---|
| `Dataset` | 数据集名称 |
| `BestPsi` | 平均 NMI 最佳的 ψ |
| `MeanNMI,MeanARI,MeanMacroF1,MeanLoadToLabelSeconds` | 最佳 ψ 下五个 seed 的平均指标和耗时 |
| `Seeds,SeedBestQs` | seed 列表及各自的最佳 q，分号分隔、按位置对应；平均结果没有一个共用的 q |
| `T,GrowthRate,SeedSampleSize` | 随机分区次数 t、衰减系数 v、实际候选样本数 s |
| `BestRunPsi,BestRunSeed,BestRunQ` | 最佳 ψ 下最佳单次运行的 ψ、seed、q |
| `BestRunNMI,BestRunARI,BestRunMacroF1,BestRunLoadToLabelSeconds` | 该单次运行的指标和耗时 |
| `BestRunUnassigned,SearchSeconds` | 最佳单次运行的未分配点数、参数搜索总耗时 |

汇总指标、耗时及衰减系数同样保留四位小数；整数参数和 seed 保留整数。返回的 `results.SummaryFile` 指向该汇总文件。汇总更新只在数据集完整运行后执行，不会用中途检查点覆盖该数据集的旧汇总记录。

| 文件 | 内容 |
|---|---|
| `q_search.csv` | 所有 `(ψ, seed, q)` 候选的指标、耗时和未分配点数 |
| `seed_best.csv` | 每个 `(ψ, seed)` 的 NMI 最佳 q 及对应结果 |
| `psi_summary.csv` | 每个 ψ 的五个 seed 平均指标和平均耗时 |
| `best_psi.csv` | 平均 NMI 最佳的 ψ 及其平均结果 |
| `best_psi_seeds.csv` | 最佳 ψ 下五个 seed 各自的最佳 q 及结果 |
| `best_run.csv` | 最佳 ψ 下单次 NMI 最高的运行参数及结果 |
| `best_labels.csv` | `best_run` 对应的样本标签 |
| `best_psi_labels_seed_<seed>.csv` | 最佳 ψ 下每个 seed 的最佳标签，共五份 |
| `search_time.csv` | `SearchSeconds` |

单次结果列为 `Psi,Seed,Q,NMI,ARI,MacroF1,LoadToLabelSeconds,Unassigned`；平均结果列为 `Psi,MeanNMI,MeanARI,MeanMacroF1,MeanLoadToLabelSeconds`。

标签 CSV 按原始数据行序保存：

| 列 | 含义 |
|---|---|
| `SampleIndex` | 从 1 开始的原始样本行号 |
| `TrueLabel` | 原始真实标签 |
| `RawLabel` | DKC 输出标签，0 表示未分配 |
| `AlignedLabel` | 匈牙利对齐后的真实类别编号，未匹配时为 `NaN` |

指标和秒数采用 `%.4f`，例如 `1.0000`；参数、计数和标签保留原始数值。每完成一个 ψ，更新 `q_search.csv`、`seed_best.csv` 和 `psi_summary.csv`；全部搜索完成后写入最佳结果与标签。若运行中断，检查点只代表已完成的 ψ，目录中旧的最佳结果可能来自上一次完整运行。

addpath(fullfile(pwd, 'tests'));
test_idkc_search(tempname);

检查包括任意真实类别编号的匈牙利对齐、类别不均衡下的 macro-F1、未分配点和额外预测簇、最佳 q / ψ 的选择、均值计算、四位小数 CSV、标签导出一致性、固定 seed 可复现性，以及汇总表的新建、追加和同名覆盖更新。全部通过后输出 `All IDKC search checks passed.`。
